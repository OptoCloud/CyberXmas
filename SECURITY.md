# Security policy

## Reporting a vulnerability

Please report vulnerabilities in this site or its code privately through GitHub's
**Report a vulnerability** button on the repository's Security tab. Do not open a public issue.

Include what you found, where, how to reproduce it, and the impact you expect. We aim to
acknowledge reports within a few days and will keep you updated until it is fixed.

Only the latest code on `master` and the live site at cyberxmas.com are supported.

## Scope

In scope: the code in this repository and the site at cyberxmas.com, for example authentication,
the editorial desk, embargo bypasses (seeing a door before it opens), injection, or abuse of the
tip and voting flows.

Out of scope: denial-of-service or load testing, social engineering, automated scanner output
without a demonstrated impact, and issues in Cloudflare or GitHub themselves (report those to
the vendor).

Please test only against your own local or preview deployment, never against other users' data.

## Not a disclosure channel

CyberXmas reports on already public incidents. Do not send undisclosed vulnerabilities in other
products through the tip form; report them to the affected vendor or CERT instead.
